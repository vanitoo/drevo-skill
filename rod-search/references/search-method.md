# Методика архивного поиска

## Карточка исследовательского вопроса

| Поле | Что фиксировать |
|---|---|
| Проверяемый вопрос | Один факт или один переход родства |
| Имена | Полная форма, е/ё, варианты фамилии, отчества, девичья фамилия, дореформенная орфография |
| Даты | Точная дата или диапазон с обоснованием |
| География | Историческая губерния/уезд/волость/приход и современное административное положение |
| Родные | Родители, супруги, дети, свидетели, восприемники |
| Контекст | Сословие по документу, профессия, место работы, часть, РВК, учебное заведение |
| Документы на руках | Семейное фото, надпись, военная карточка, индекс, акт ЗАГС |
| Ограничения | Приватность, неясный населённый пункт, недоступный архив |

## Последовательность

1. Сверить все исходные материалы и пометить, что действительно известно.
2. Установить историческое место и его изменения: одинаковые названия могли относиться к разным пунктам.
3. Выбрать документ по типу события и времени; искать не только фамильным поиском, но и по описям/приходу/делу.
4. Менять по одному параметру: фамилию, место, год, отчество, старое написание, соседний пункт, приход или военкомат.
5. При обрезанной строке выдачи найти полную карточку или изображение, не угадывать отсутствующие буквы.
6. Дословно выписать значимый текст, отдельно пометить нечитаемые символы и ошибки OCR.
7. Сопоставить несколько независимых признаков идентификации. Устанавливать родство только при наличии отдельного основания, не по одному отчеству.
8. В журнале фиксировать и положительный результат, и точный охват отрицательных попыток.
9. Рассмотреть альтернативные гипотезы и исключённых однофамильцев.
10. Предложить следующий конкретный архивный документ или запрос, который может закрыть ближайший пробел.

## Отчёт

Использовать шаблон ../templates/research-report.md. Для каждого результата: точный источник, дата доступа, архивный шифр, скан, доказательный статус и конкретное решение по GEDCOM. При сомнениях оставить гипотезу в отчёте без изменения дерева. В частном проекте действуют дополнительные правила AGENTS.md и PROJECT_RULES.md.
